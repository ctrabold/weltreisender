{{- /* As the hugo-book hook (anchor link), plus: the first heading of a page that repeats the page title (every diary post starts with `## `) becomes the page's

, diary posts only (other pages show their beginning in category lists); all other headings keep their level. `## Title {icon="directions-bike"}` puts a decorative icon in front of the text (aria-hidden, not in the anchor): an assets/icons/.svg from the icon sprite (monochrome), otherwise the text, e.g. an emoji. Styles: .book-title in assets/styles/custom.css. */ -}} {{- $level := .Level -}} {{- $class := .Attributes.class -}} {{- $diary := and .Page.File (findRE `^docs/20\d\d/` .Page.File.Path) -}} {{- if and $diary (eq .Ordinal 0) (eq .Level 2) (eq .PlainText .Page.Title) -}} {{- $level = 1 -}} {{- $class = delimit (slice "book-title" $class) " " | strings.TrimSpace -}} {{- end -}} {{- with .Attributes.icon -}} {{- if resources.Get (printf "icons/%s.svg" .) -}} {{- else -}} {{ . }} {{- end -}} {{- end -}} {{- .Text -}} {{- if default true .Attributes.anchor -}} {{- end -}}
